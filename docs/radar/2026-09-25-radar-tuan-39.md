## 4. Việc còn lại phải làm ở máy local

Phiên cloud không ping IndexNow được (proxy chặn `api.indexnow.org` và
`www.bing.com`). Khi từng bài lên, chạy:

```bash
node scripts/indexnow.mjs https://techvision.click/articles/<slug>.html https://techvision.click/blog.html
```

cho lần lượt 5 slug ở bảng mục 2. GitHub Action `release-scheduled.yml` tự gỡ
cờ `noindex`/`scheduled` đúng giờ và tự ping, nên phần này chỉ cần làm tay nếu
Action lỗi.
